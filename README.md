# GitSplit

![GitSplit](GitSplit.png)

GitSplit 是一款基于 Android 的文件分卷压缩与恢复工具，面向需要将大文件拆分保存、传输或备份的使用场景。

应用采用系统文件选择器管理文件访问，无需申请全盘存储权限。用户可以选择任意文件，将其压缩为多个小体积分卷，也可以选择完整的分卷集合恢复原始文件。

## 主要功能

### 3 MiB 分卷压缩

- 将单个文件压缩为 ZIP 分卷文件。
- 每个分卷最大约 3 MiB（3,145,728 字节）。
- 使用 ZIP 高压缩级别减少存储空间占用。
- 生成 Bandizip 风格的分卷格式：

```
example.z01
example.z02
...
example.zip
```

最后一个 `.zip` 文件包含 ZIP 完整结构，可与前面的 `.z01`、`.z02` 等分卷一起恢复。

### 分卷恢复

- 支持一次选择全部分卷文件。
- 自动检查分卷编号和完整性。
- 按顺序合并分卷并恢复原始文件。
- 恢复过程中保留文件名，并自动处理同名文件冲突。

## 使用方法

### 创建分卷

1. 点击“选择文件并创建 3 MB 分卷”。
2. 选择需要压缩的文件。
3. 选择保存分卷的目标文件夹。
4. 等待压缩完成，保存全部生成的分卷文件。

### 恢复文件

1. 点击“选择全部分卷并恢复文件”。
2. 同时选择同一组 `.z01`、`.z02`、`.zip` 文件。
3. 选择恢复文件的目标文件夹。
4. 等待恢复完成。

## 注意事项

- 所有分卷必须完整保存，缺少任意一个分卷都会导致恢复失败。
- 不要修改分卷文件名，否则应用无法识别文件顺序。
- 分卷文件需要一起移动或备份。
- 当前版本主要针对单文件压缩与恢复设计。

## 技术信息

- 平台：Android
- 开发语言：Java
- 最低支持版本：Android 10（API 29）
- 构建工具：Gradle + Android Gradle Plugin
- 文件访问方式：Storage Access Framework

## 开源与开发

GitSplit 是一个轻量级 Android 工具项目，代码结构保持简单，便于学习 Android 文件处理、ZIP 压缩、分卷读写以及系统文件访问接口的实现。
